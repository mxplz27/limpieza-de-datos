# Limpieza de Datos con Python

## Descripción
Este proyecto realiza la limpieza y preparación de un conjunto de datos utilizando Python. Su objetivo es identificar y corregir datos que puedan afectar el análisis de la información.

## Archivos del proyecto

- `datos_para_limpiar.py`: contiene el código utilizado para realizar la limpieza de los datos.
- `datos_limpios.csv`: contiene los datos después del proceso de limpieza.

## Herramientas utilizadas

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## Procesos realizados

- Exploración inicial de los datos.
- Identificación y tratamiento de valores faltantes.
- Revisión de datos fuera de los rangos establecidos.
- Eliminación de registros que no cumplen las condiciones definidas.
- Escalado de datos numéricos utilizando `MinMaxScaler`.
- Guardado de los datos limpios en un archivo CSV.

## Instalación

Instalar las librerías necesarias con los siguientes comandos:

```bash
pip install pandas
pip install scikit-learn
```

## Ejecución

Para ejecutar el código desde la terminal, utiliza:

```bash
python datos_para_limpiar.py
```

## Resultado

Al finalizar el proceso, se obtiene un archivo CSV con los datos limpios, preparado para continuar con su análisis.
